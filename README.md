# Claude Code 一个月多少钱：Pro 与 Max 的真实月费、用量限制，和国内没有外币卡的付法

Claude Code 没有自己的价目表。你在官网找不到一个单独标着「Claude Code」的付费项，因为它跟着 Claude 订阅档位走：Pro 每月 20 美元，Max 5x 每月 100 美元，Max 20x 每月 200 美元，年付的 Pro 折合每月约 17 美元。免费档不含 Claude Code，这是硬性的。

所以「Claude Code 一个月多少钱」这个问题，准确答案是：20 美元起步，100 美元是绝大多数全职写代码的人真正会落在的位置。中间这条线怎么划，值得说清楚。

## 为什么它没有独立定价

Claude Code 是订阅权益的一部分，不是单独售卖的软件。官方定价页的功能对照表里，Claude Code 这一行在 Free 档写的是 No，Pro、Max 5x、Max 20x 全是 Yes。

这种绑定方式有个后果：你付的钱对应的是「用量额度」，不是「功能解锁」。三档订阅能用到的模型基本一致，差别在你能烧多少。Pro 大约是免费档单次会话额度的 5 倍以上，Max 5x 是 Pro 的 5 倍，Max 20x 是 20 倍。花钱买的是不被打断的时间。

## 用量限制是两层，不是一层

Claude Code 的额度卡在两个地方：5 小时滚动窗口，以及每周总量上限。任何一个撞到，当天就写不下去了。

2026 年这套限制动过好几次。5 月 6 日，5 小时窗口的额度被永久翻倍，同时取消了高峰时段限流。随后又叠加了一轮临时 50% 的每周额度提升，这个促销在 9 月 13 日结束。9 月 14 日起，每周额度的永久基线定在原始值之上 25%——换算下来，比促销期间还少了大约 17%。

这些调整都没有动价格，动的是同一个价格能买到多少。

值得注意：官方从来没有承诺过「Pro 每周给多少小时」这类确切数字。不同任务消耗差别极大，同样的工作量，改一个小文件和要求 Claude Code 遍历整个仓库，额度消耗完全不是一回事。所以别人说「Pro 够用」，对你不一定有参考价值。

## 还有一条按 token 付费的路

如果你不订阅，也可以拿 API key 直接跑 Claude Code，纯按量计费。参考费率大致是：Sonnet 档位约 $2 / 百万输入 token、$10 / 百万输出 token；Opus 档位约 $5 / $25；Haiku 档位约 $1 / $5。开启 prompt caching 能把重复上下文的输入成本压下来一大截。

什么情况下按量更划算？脚本化、定时触发、CI 里跑的那种自动化任务。这类用法对订阅额度是纯粹的消耗，而按量付费多少钱办多少事。

什么情况下按量更贵？每天开着 Claude Code 干一整天活的人。有第三方测算提到，企业部署下 Claude Code 的平均成本大约在每开发者每个活跃日 13 美元，折到每月 150 到 250 美元——比 Max 20x 还高。这也是为什么重度使用者最终会回到订阅。

## 账单上容易漏算的三件事

第一，官方价格不含税。你在定价页看到的 20 美元、100 美元，下面还有一行小字写着价格不含适用税费。

第二，年付只用一次钱，但只有 Pro 有年付折扣。$200 一年换 $20 一个月的价格，省 60 美元。Max 没有对应的年付优惠。

第三，外币卡的隐形成本。国内用户要付这笔钱，得先解决支付通道——开卡费、充值手续费、汇率点差，加上支付失败重来的时间。这些不在 Anthropic 的价目表里，但确实在你的总支出里。

## 决定用代订阅之前，这几件事值得知道

**它对网络环境有要求。** 平台会在提交订单前检测 IP 类型、DNS 泄露和浏览器指纹。数据中心 IP（常见的机场节点、VPS）通过率很低，住宅 IP 才是关键。只准备了机场节点就去下单，大概率卡在这一步。

**续费和订阅生效不是每次都顺。** 公开记录里有真实案例：有用户的三月套餐没能按期自动续费，另有一笔两月套餐订单显示完成但账号仍是免费版，最后走的是退款或退款方案。也有用户遇到「修复订阅」弹窗反复出现、客服确认订阅正常时不需要重复点击的情况。平台最终给了处理，但过程需要沟通。买多月套餐之前，把这一点算进去。

**它是第三方，不是官方渠道。** 账号归你自己，但订阅动作由平台代做。这类服务的售后边界、退款条件，值得在付款前读一遍当期规则，而不是到期出问题时才去看。

**Claude Code 在 Pro 里是有的。** 2026 年 4 月，官方短暂测试过把 Claude Code 从 20 美元的 Pro 档移到 100 美元起——当时官方说法是针对约 2% 的新 Pro 注册用户做的小范围定价测试，定价页随后改了回去，已有 Pro 和 Max 订阅者不受影响。但这说明一件事：这个捆绑关系不是写死的。真要长期用，别把「Pro 永远包含 Claude Code」当成不可变的假设。

## 到底选哪一档

如果你一周只写几个晚上的代码，Pro 的 20 美元（或年付 17 美元）是目前唯一合理的入口，按量付费在这种场景下反而更容易超支。

如果你白天基本开着 Claude Code，Pro 的额度大概率会在某个下午卡住你。中断一次任务的代价通常高于从 20 涨到 100 的那 80 美元，Max 5x 是这类人的实际落点。

如果你在跑持续的 agent 工作流、多项目并行，或者经常一天烧掉几百万 token，Max 20x 的 200 美元通常比同等的 API 账单便宜。这不是「更强」，只是批量价。

团队的话，先确认到底需要哪种席位——Standard 席能不能用 Claude Code，直接决定了你的月费是二三十美元一席还是上百美元一席，这个差别比任何折扣都大。

## 常见问题

**Pro 的 20 美元一个月，够跑 Claude Code 吗？**
够不够取决于你用得多密。一天几次小改动，够。整天开着做重构，不够。官方不给确切小时数，因为同样的额度在不同任务上消耗差别很大。

**可以只买 Claude Code 不买订阅吗？**
可以，但那是 API 路线——按 token 计费，没有固定月费。跑自动化脚本合适，长时间交互式使用不合适。

**免费档能用吗？**
不能。官方功能对照表里 Claude Code 在 Free 档明确标为不支持。

**代订阅之后，账号是谁的？**
账号始终是你自己注册的那个，平台通过登录凭证完成订阅动作，不接管账号。但订阅的续费由平台执行，这就是为什么续费异常时会需要走售后。

**3 个月套餐真的比 1 个月划算吗？**
从月均看是的，BeWild 的 Claude 三月套餐折合大约每月 156 元，比单月的 168 元左右低。前提是你确认自己会用满，并且接受前面提到的续费风险。
